# Project Rules

## Git / GitHub
- NEVER push to GitHub under any circumstances
- NEVER create pull requests
- NEVER run `git push`, `gh pr create`, or any command that sends code to a remote
- Local commits are fine if explicitly requested, but nothing leaves the machine without direct instruction from the user

## Deployment
- Nothing ships to production (Render) without Adi reviewing it first
- All changes stay local until cleared

## General
- No new files unless absolutely necessary
- Read before editing
- Never commit secrets or .env files
